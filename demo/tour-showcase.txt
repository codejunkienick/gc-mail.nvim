# The developer showcase tour: the chat, a cut, then the mailbox as the
# mail client for the agents, about 57 seconds.
# Steps: key, type, wait, say, agent (see record.sh).

say Mail and chat with agents, inside Neovim
wait 600

# (1) Chat with the mayor beside the notes.

wait 500
key space m c
wait 1200

say Type, Esc, then Space m s sends it
wait 500
key i

key Escape
key space m s

key i

key space m s

key q
wait 600
